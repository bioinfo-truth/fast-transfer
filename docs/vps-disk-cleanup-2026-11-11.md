# VPS磁盘清理与上传后端候选

2026-11-11，用户要求清理VPS磁盘。只读占用检查及/proc引用检查后，删除历史1 GB/5 GB确定性合成测试的五个源/回读路径、三处OpenList审阅编译缓存/依赖副本，并执行apt-get clean。没有删除运行目录、结果、事件、配置、已安装程序或源码；没有停止服务或操作云端对象。硬链接导致逻辑文件总大小不等于实际释放量。

根文件系统清理前可用8,360,685,568字节（7.79 GiB），清理后24,323,592,192字节（22.65 GiB），增加15,962,906,624字节（14.87 GiB）。清理后仅检查metadata，确认原NCBI样例、五份指定原始记录和原授权文件仍存在，未读取凭据内容。其他较小历史测试数据继续保留。

历史1 GB/5 GB测试成功证据不变，但已删除上述本地合成源/回读副本，不能继续称这些副本仍保留。编译缓存可重建，重建需要重新获取或提供已校验的固定公开依赖。实际私有路径和连接地址不公开。

用户询问VPS上传后端时，当前建议为候选方向：优先评估BaiduPCS-Go原生客户端，保留OpenList+rclone作为备选。理由是百度单一交付目标下组件较少、较容易直接管理任务及临时文件；这不是已测得的速度/空间优势。当前境内原生登录及分享已获用户实测确认，不能外推为VPS原生上传可用。OpenList+rclone已有历史5 GB上传及完整回读证据，清理没有卸载它。下一步建议用同文件/同出口比较VPS两方案吞吐、实际磁盘峰值及恢复行为后再替换。尚未部署或运行该比较，用户尚未确定替换后端。BaiduPCS-Go为第三方客户端，不等同百度官方SDK或开放平台API。
