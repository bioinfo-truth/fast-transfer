# 百度开放平台文件分享服务：开通备选方案

2026-11-08 核对官方公开文档。当前用户已说明未开通此服务，选择先用个人网盘正常客户端手动建链；以下只是未来自动化的备选准备，没有代为申请、购买、联系商务或调整授权。个人网盘的普通分享功能与开发者分享 API 是不同渠道，不因 API 条件推断客户端无法分享。

## 官方开通路线

1. 登录[百度网盘开放平台](https://pan.baidu.com/union/console/applist)，按[企业开发者认证流程][cert]提交认证。公开材料清单包括营业执照、统一社会信用代码、企业负责人/法人身份证件及联系方式；身份材料只在官方表单处理，不通过项目仓库或本对话收集。认证文档说明需要人工审核，实际条件/周期以控制台为准。
2. 按[文件分享服务接入指南][guide]联系商务确认服务及费用。页面列出的商务邮箱为 **ext_mars-union@baidu.com**，也可用指南里的客户经理企业微信入口。文件分享服务是单独付费能力，没有在该页面公布统一价目。
3. 说明已有 Xtransfer 个人应用，请商务确认能否给现有应用开通、是否需要应用主体/授权调整；不能假设既有 AppID 或 access_token 自动获得分享服务。确认购买及开通后，再按[创建分享链接 API][share]接入正确应用 ID、文件 ID、期限与提取码。密钥/授权均不应发到公开仓库。

企业开发者认证和文件分享服务，并非“企业网盘订阅”的同义名称；官方指南还说明该分享接口不与企业版链接互通。现有网盘会员/存储权益也不是 API 开通证明。

## 向商务确认的具体事项（待答复）

- 本项目为中国境内客户代下载海外公开生物数据，存入服务方网盘后创建有限期/提取码分享；这种商业交付场景是否符合准入和协议。
- 可接受的企业/经营主体类型，现有 Xtransfer 是否可沿用，是否需要变更应用或重新授权。
- 是否有最低消费、开通费；建链/解析等调用如何计费，接收端下载流量及可能附加的加速权益是否另收费。
- 调用配额/频率、有效期/提取码限制、失败请求收费及测试额度。

以上是询价/准入问题，尚无答复，不是既定价格、权限或服务承诺。不要未经确认就购买，也不应为探测分享能力而换用其他应用示例凭据。

用户提供的资料可作线索，但混用了不同渠道的参数，示例不能直接运行。没有执行其中的代码，没有发送分享请求或读取账户凭据；此前的自动分享停止边界保持不变。

| 项目 | 核对结果 |
| --- | --- |

| 返回值 | 先核对 `errno`，成功结果在 `data.link`、`data.short_url` 等字段；不是资料示例的顶层 `shorturl`/`link`。 |

| 频次 | 指南仅说明按调用行为限频，未给出统一“每日几百次”或 VIP 数值；也不能把错误码 `11000` 一概解释为分享额度耗尽。随机等待不能保证不触发限制。 |
