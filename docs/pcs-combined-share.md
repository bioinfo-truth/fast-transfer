# 同一次登录验证原样例并创建一次分享

2026-11-11：合并入口已编译、安装，并通过合成和本地 TLS 测试；真实登录与分享尚未执行，不能视为在线兼容性或领取成功证明。

## 本人操作

现在可以无凭据查看帮助：

```sh
BaiduPCS-Go share --session-only --help
```

实际执行前必须先准备可信的原样例私有清单。来源是原上传任务的五份指定私有记录，经 `fast_transfer.original_sample.load_original` 关联校验后只导出 ExpectedObject 字段；不要复制 OAuth、Cookie、整个会话记录或令牌。经用户明确批准两机最小元数据传输后，已在境内私有目录准备并校验真实清单；私有路径及值不发布。账号指纹、fsid、路径、大小、MD5、SHA256及清单摘要必须来自原记录，不能用本次查询结果反过来填期望值。清单为本人所有、0600普通文件，不能是符号链接；摘要校验仅证明内部一致性，不证明来源可信。

准备好后，以下是本人执行的命令模板，路径与天数需要替换：

```sh
BaiduPCS-Go share --session-only \
  --expectations /PRIVATE/PATH/original-sample.json \
  --period 7 \
  --allow-own-share-page
```

`7` 只是示例，需本人选择；当前程序支持1–7天作为测试边界，不是百度平台的期限上限声明。提取码在交互终端隐藏输入，当前只接收四位小写字母或数字，不通过参数或聊天传递。本人输入 `LOGIN-SHARE` 后，在同一流程隐藏输入账号和密码；不要先单独登录再退出重做。

## 实际执行前待明确的范围

- 是否允许读取一页自己的最新分享记录：该页可能含其他历史分享的元数据，响应上限64KiB、最多接受128条，不翻页。缺少明确参数即在登录前停止。所审阅的固定客户端源码中没有可直接替代它的精确对象映射查询。
- 分享有效期，以及本人在终端选择提取码。
- 从原任务指定记录准备可信私有清单。此准备已完成，仅传输九项ExpectedObject字段；未迁移令牌、Cookie或密码，未读取用户终端。

## 流程与限制

同一Go进程完成一次认证、旧账号SHA256匹配、精确原文件元数据校验、持久化单次意图、一次创建、返回分享ID与自己分享记录中的唯一原fsid及路径匹配、提取码和剩余期限校验。只允许固定HTTPS路由，正常TLS校验，不跟随跳转，不自动重试。旧WAP密码协议在线兼容性仍未知，验证码或其他挑战即停。

链接和提取码经独立私密管道，仅显示在本人前台控制终端，普通状态输出不包含它们。进程不保存凭据，但不能保证内存被安全擦除，退出不等于服务端注销。

单次意图记录按账号指纹与原fsid绑定，私有目录0700、文件0600；创建前持久写入并同步磁盘，结果未知后换进程也会在登录前停止。记录包含摘要、期限、状态、时间及新分享ID，不存密码、Cookie、链接或提取码。不要删除意图文件来盲目重试；未知结果需要人工核查。

分享创建是按路径提交，无法保证云端并发改动下与先前fsid原子绑定；事后映射不匹配时不交付链接，不自动撤销。自己的分享记录匹配不等于接收端可访问，`recipient_access_verified`始终为false；本轮没有进行领取验证。
