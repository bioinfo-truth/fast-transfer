# MVP 里程碑与当前边界

目标：操作人员录入公开生物数据文件链接或 manifest → 下载和源站校验 → 上传百度并核验 → 受控分享/人工回填 → 中国境内测试用户领取并校验。第一版不包含淘宝、支付、项目号解析、完整网站和收费。已有三个工具验证保留，不重复运行；跨 OpenList 服务重启的分片恢复已知受限，不作为 MVP 前置门槛。

执行清单使用现有 Slack M1–M6，由协调会话核实后更新；本实现会话不写 Slack、不重复创建 Issue。与已有 GitHub 执行事项关联即可。

## 当前实际结果与下一步

用户已批准一次真实样例测试，并追加完整性通过后生成该精确文件链接。已有 NCBI FASTA 1,379,902 字节已在原新目录续办成功，源/远端长度及完整回读 MD5/SHA-256 一致。原始解析失败、只读核查及新会话续办均保留，无第二个云端目录、无覆盖/删除。见[真实样例记录](mvp-live-sample.md)。

分享创建及访问核验仍 pending，未发送分享 API 请求。官方新服务要求企业认证及付费开通，当前个人应用没有已确认开通信息；需既有服务/AppID 核实或本人已登录正常客户端人工为精确文件建有限期分享。没有购买、重新 OAuth、换 Cookie 或扩大持久权限；不重复申请一般 M3 测试授权。可用链接只私密返回，不进公开证据。

本轮的短期内存令牌引用/进程已结束，无新令牌文件；原授权、源、对象保留。此轮不授予未来测试许可，M6 真实境内端和领取证据仍未具备。
