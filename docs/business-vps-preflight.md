## 主机与依赖只读检查

仅连接项目既有业务VPS SSH目标，保留既有主机密钥校验；公开收据不含真实地址、主机名、账号或私有路径。

- Linux x86-64，现有Python **3.13.5**；开发主机测试解释器3.14.4，二者分开记录。
- 正常登录PATH能定位BaiduPCS-Go，文件可执行，仅读20字节ELF头确认64位x86-64；**未启动客户端（连version也未执行），避免初始化时读取登录配置**。这不证明可登录或业务可用；历史有贴吧profile HTTP超时/旧登录方式问题报告，本次未复现，也不能仅凭它确认当前唯一失败根因。
- 隔离Python默认搜索路径没有可导入fast_transfer；这**不证明源码在整台机器上不存在**。当前没有已核实的新版部署目录/版本或业务MCP验收记录，不猜目录、不扫旧文件。
- 将候选30份公开项目Python源码通过stdin仅在VPS内存执行compile语法检查，全部通过，**未执行项目模块、未写代码/部署文件**。ssl/termios/fcntl/select可导入，系统CA计数148，TLS校验配置可设置、keylog关闭。它是语法/依赖预检，不是程序导入/启动或官方TLS握手成功证据。
- 没有对百度发DNS/TCP/TLS/SSE或认证请求，没有查询公网出口/读取路由器或代理配置。代码不使用应用层代理不等于流量未受软路由、NAT或透明策略影响；SSH可达、业务IP和系统CA存在都不能推断百度链路出口或MCP可达性。

## 运行角色应当如何安排

| 角色 | 责任与边界 |
| --- | --- |
| 开发主机 | 代码、合成/本地TLS测试；用户认为可用BaiduPCS-Go可保留为独立工具路线，本轮未验证其登录，不作为业务VPS MCP验收 |
| 海外业务VPS | 海外源下载/校验、已有Xtransfer上传路径；官方MCP的必要只读/分享前置和未来获准建链均在此节点验收，保留原云端对象 |
| 操作者浏览器 | 用户自己核对并批准官方设备页面，可以在操作者电脑；不意味着开发服务器代发MCP |
| 授权/令牌 | 若以后确需新设备grant，申请、兑换与MCP使用应在VPS同一受审进程完成；不要把开发机取得的token/AppSecret转运到VPS作为默认方案 |

当前旧上传器已验证的路径与生成外链是两个环节；MCP候选用于业务节点的自动化接口，不因此改成大文件流传输通道或重传原样例。
