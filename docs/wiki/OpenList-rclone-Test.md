## 缓存与资源边界

每 50 ms 采样的 OpenList 临时文件逻辑大小峰值分别为 1,379,902 与 134,217,728 字节，达到完整文件大小；128 MiB 样例分配块峰值也为 134,217,728 字节。不能将标准输入上传解释为无完整缓存。

为保留现有磁盘缓存，本轮全部测试临时目录、克隆配置和数据库位于独立挂载命名空间内的 192 MiB tmpfs，测试结束后卸载，子进程全部结束，临时目录为空。完整 payload 未写 VPS 磁盘；这是本轮选择 RAM 承载完整缓存的结果，普通磁盘部署仍需容纳完整文件。tmpfs 也占内存，不能据此主张大文件可无限扩展。

测试进程组设置 1100 MiB 内存上限、禁用交换、2400 秒运行上限；实际样例流程约 68.5 秒。运行中一次 systemd MemoryPeak 观测为 207,036,416 字节，服务结束后属性已不可取，不能作为最终精确峰值。进程 RSS 采样求和最高为 191,463,424 字节，可能重复统计共享页。主机空闲空间保留 5 GiB＋256 MiB 提前停止余量。rclone 并发 1、检查线程 2、buffer 16 MiB、命令重试 1；OpenList 内部分片有自己的重试，未独立统计实际请求次数。

首轮因测试配置将整数 `auto_memory_limit` 误设为布尔值而启动失败，未进入网盘传输；改为整数 0 后，在独立第二次运行完成上述闭环。失败记录保留，不将两次都记为成功。
