# 首轮验证方案

## 环境

记录 VPS 服务商、区域、套餐、系统、磁盘剩余、账号等级、网盘客户端版本及 commit、测试时间和网络条件。勿记录 token、Cookie、订单个人信息或未公开数据。

## 测试矩阵

1. 选美国和欧洲的公开源站各一个或多个文件，覆盖小文件与代表性的较大文件；保留来源及官方校验信息。
2. 比较源站到 VPS、VPS 直传百度网盘、分享链接到境内客户；记录总时间、有效吞吐、流量、失败重试和峰值磁盘占用。
3. 在白天和晚高峰重复；说明样本量、文件、账号级别和时间，避免把峰值当 SLA。
4. 上传中途终止进程，重启后核实重传字节和结果；再测试网络中断及状态过期。对比包含续传提交的 BaiduPCS-Go 构建与开放平台客户端。
5. 通过源站校验、本地校验、上传分片及条件允许的重新下载分别记录验证层级。对超出网盘单文件或 VPS 空间的文件提前识别。

## 输出

保留每次测试的机器与版本、源站、文件大小、各阶段耗时、成功率、重传、费用和限制，并根据结果决定是否需要其他地域或代理。不得先承诺价格和时效。

## 组合策略与对照测试

- **离线 URL 拉取**：先用小型公开文件，确认网盘真正从源站获取、完成且校验一致；记录重定向、大小、并发和任务限制。提交成功不等于成功交付。
- **上传节点**：先测试 BaiduPCS-Go 默认动态分配，再对照项目当前支持的静态节点；记录客户端版本、实际目标、时段、完整上传耗时、失败率和是否秒传。上传与分享分别验证，不预设旧讨论中的地址仍可用。
- **大文件与小磁盘**：对比逐文件暂存、双遍读取后按块上传、独立分卷；记录下载遍数、源站字节数、VPS 入出流量、上传量、峰值磁盘、费用、完整性及客户操作。双遍读取要检查源文件版本、Range 行为及分片哈希。
- **备用 NAS 路径**：对同一文件比较 VPS 直传网盘和境内主机经 VPS 获取、NAS 暂存后上传网盘。检查挂载中断、可用空间和系统盘保护；仅在软路由规则及代理流量计数通过小流量核验后扩大测试。
- **异常和恢复**：人为中断下载、上传、VPS 进程和 NAS 连接；检查恢复、真实重传量、状态过期及清理。切换 VPS 后能否复用远端分片必须单独验证。

## 2026-11-07：个人 OAuth 小文件验证

- 公开 NCBI 测试文件 1,379,902 字节；美国 VPS 从源站下载并匹配官方 MD5。
- 使用同一应用授权，美国 VPS 对百度预上传请求得到 HTTP 403（响应非百度 API JSON），未创建网盘文件；当前主机预上传返回成功。根因尚不明确，不能据此断定账号限制或服务端地理限制。
- 当前主机完成下载、源站 MD5 匹配、上传分片回执与网盘创建结果大小校验；网盘返回文件标识。未重新下载验证网盘文件字节，也未测试分享、速度、大文件、续传或 VPS 直传。
- VPS 测试时 `/tmp` 空间不足以满足 5 GiB 预留，后改用系统盘工作目录；记录这一空间保护行为。
- 实际仅测试小文件，不得推导吞吐、稳定性或自动交付能力；后续需排查 VPS 的 API 请求及网络路径，继续使用脱敏日志。

## 2026-11-07：AList + rclone 小文件闭环

美国测试节点经 AList v3.66.0 与 rclone v1.76.0 完成 NCBI 公开文件上传百度、远端大小验证和回读 MD5 校验。标准输入上传的 AList 临时文件峰值达到完整文件大小；本组合未解决超磁盘单文件问题。64 MiB 本地 WebDAV 对照与中断重传也通过内容校验，未证明云端断点续传。详见[测试记录](https://github.com/bioinfo-truth/fast-transfer/wiki/Transfer-Tools)。分享、客户领取、令牌自动刷新、大文件和长期性能仍待验证。
