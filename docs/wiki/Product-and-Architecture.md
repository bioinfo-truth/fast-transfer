# 产品与架构

## 目标与范围

用户提交公开数据项目号、期望的样本范围和文件类型，服务识别并获取公开文件，上传到服务方百度网盘，再向客户交付分享链接和文件清单。客户群体为中国境内的生信研究人员和机构。数据范围首先限定为公开且允许获取和交付的数据；不自动处理受控访问或未经授权的数据。

## 目标链路

```text
海外数据库 → 美国 VPS 下载与校验 → 百度网盘 → 分享链接 → 客户
                     ↑
              数据库解析插件
```

首台测试节点倾向于洛杉矶。先测直连百度网盘，不预设购买境内代理；如果速度或可用性不足，再评估代理的流量成本与性能。不限量宣传、共享端口和实际持续吞吐是不同概念，应确认供应商条款并实测。

## 数据与交付

解析结果需列出项目、样本、run、文件类型、来源、大小及源站校验值。用户在执行或报价前确认样本范围与文件格式；未知大小、关联不明、源不可用或受控数据进入异常队列。清单标明来源与版本，上传完成不等于网盘端到端字节校验完成。分享时标注保留期限。

## 磁盘和传输

VPS 硬盘有限，优先逐文件处理，限制缓冲和保留系统空间；可逐步增加下载与上传的文件级流水线。异常时暂停并告警，不无限制下载。单文件超过可用空间时评估双遍读取和按范围取数据，先验证源站稳定性、接口预上传哈希要求、流量和恢复能力；超过网盘单文件上限则先确认拆分及客户合并需求。

BaiduPCS-Go 是优先测试的上传与分享候选。其 2026-08-25 主分支提交声称恢复上传断点续传，早于此提交的 v4.0.2 发布包不应默认具备该能力；需在真实账号测试。Go SDK 和现有 Python PoC 可用于接口验证或对照，不假定它们能共享上传状态。

## 自动化

内部清单 → 下载 → 校验 → 上传 → 生成分享 → 交付。淘宝订单状态、付款、项目号输入以及消息发送的开放接口和使用规则尚待核实，先以人工录入和交付验证核心流程。避免将第三方工具对外服务的许可或平台授权视为已确认。

## 当前实现状态

本仓库的 Python PoC 基于清单逐文件下载并尝试百度开放接口上传，支持本地磁盘预算及源站 MD5 校验；仅通过模拟测试，未完成真实网盘上传。无续传、分享或数据库解析。固定 4 MiB 分片与 1024 片限制可能导致大文件不可上传，务必先修正及验证。失败会删除临时文件，重跑重新下载；不得用于正式订单。
