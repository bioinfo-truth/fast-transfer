## 目标与范围

用户提交公开数据项目号、期望的样本范围和文件类型，服务识别并获取公开文件，上传到服务方百度网盘，再向客户交付分享链接和文件清单。客户群体为中国境内的生信研究人员和机构。数据范围首先限定为公开且允许获取和交付的数据；不自动处理受控访问或未经授权的数据。

## 目标链路

```text
海外数据库 → 美国 VPS 下载与校验 → 百度网盘 → 分享链接 → 客户
                     ↑
              数据库解析插件
```

首台测试节点倾向于洛杉矶。先测直连百度网盘，不预设购买境内代理；如果速度或可用性不足，再评估代理的流量成本与性能。不限量宣传、共享端口和实际持续吞吐是不同概念，应确认供应商条款并实测。

## 数据与交付

解析结果需列出项目、样本、run、文件类型、来源、大小及源站校验值。用户在执行或报价前确认样本范围与文件格式；未知大小、关联不明、源不可用或受控数据进入异常队列。清单标明来源与版本，上传完成不等于网盘端到端字节校验完成。分享时标注保留期限。

## 磁盘和传输

VPS 硬盘有限，优先逐文件处理，限制缓冲和保留系统空间；可逐步增加下载与上传的文件级流水线。异常时暂停并告警，不无限制下载。单文件超过可用空间时评估双遍读取和按范围取数据，先验证源站稳定性、接口预上传哈希要求、流量和恢复能力；超过网盘单文件上限则先确认拆分及客户合并需求。

网盘适配基线采用 OpenList + rclone，历史 AList 实测作为对照保留。直接 OAuth/API 上传器已验证小规模跨进程分片恢复，继续用于细粒度上传控制。BaiduPCS-Go 作为动态节点、分片和恢复设计的源码参考，不要求重新 Cookie 登录；不同客户端的 uploadid、应用权限和状态不假定可互换。官方 SDK 示例可用于接口研究，不把身份未核实的仓库当成官方依赖。

## 自动化

内部清单 → 下载 → 校验 → 上传 → 生成分享 → 交付。淘宝订单状态、付款、项目号输入以及消息发送的开放接口和使用规则尚待核实，先以人工录入和交付验证核心流程。避免将第三方工具对外服务的许可或平台授权视为已确认。

## 当前实现状态

本仓库的 Python PoC 基于清单逐文件下载并尝试百度开放接口上传，支持本地磁盘预算及源站 MD5 校验；已在境内主机通过一次 OAuth 真实小文件上传验证；该 PoC 早期美国 VPS 预上传曾返回 HTTP 403；随后独立 AList 和直接 OAuth 实验已完成直传及回读，详见项目总览，不能将早期失败推广到当前所有实现。无续传、分享或数据库解析。固定 4 MiB 分片与 1024 片限制可能导致大文件不可上传，务必先修正及验证。失败会删除临时文件，重跑重新下载；不得用于正式订单。

## 组合传输策略

针对每个文件，依据公开数据源及网盘能力、文件大小、磁盘预算、时效、成本和已验证的恢复能力选择策略；路径失败时记录原因并按预算切换，未经验证的路径不能自动视为可交付。

1. **网盘直接拉取 URL（待验证）**：如百度离线下载支持目标公开数据源和文件，可绕过 VPS 大文件暂存。先验证服务端实际拉取、URL 与重定向支持、文件大小、速度、限制及最终校验；提交成功不等于下载和验证成功。
2. **VPS 逐文件暂存上传（首个主路径）**：美国 VPS 下载、校验后上传；小磁盘需限制并发、空间预留及清理，多个文件可在安全预算内流水处理。先使用官方动态上传节点；在当前任务返回的 HTTPS 候选中评估择优与有限失败切换，尚未实测。确认实际承载数据的地址，排除秒传影响。上传和分享分别验证。
3. **双遍读取与网盘内部分片（待验证）**：若接口预上传需要完整分片哈希，第一遍读取计算全文件及各分片哈希，第二遍用有限缓冲读取并上传；记录额外时间、源站流量和费用。逐块复核两次内容，只有源站支持可靠范围读取和对象版本稳定时才尝试按范围恢复。网盘完成合并及验证前不交付。
4. **独立分卷（待验证）**：顺序生成和上传可容纳的独立分卷，记录顺序、大小、分卷哈希及原文件哈希。明确告知客户需下载全部分卷并合并，提供可验证的合并说明；不得将任意分卷称为可独立分析的 FASTQ。
5. **境内主机与 NAS 暂存（备用）**：需要更多空间、缓存或对照时，使用境外 VPS 代理获取数据并写入 NAS，再上传网盘。比对整条路径的速度、成本和稳定性，处理 NAS 断连并确保不会回退写入系统盘。

组合策略不意味着已实现：选择、自动切换、跨进程续传和跨 VPS 复用已上传分片都需单独验证。只有明确支持且验证成功的路径才纳入自动调度；超限或权限不明时进入人工处理。不得依赖更换节点即可继承已上传的分片。

## 境内网络与存储约束

现有境内主机有网络挂载的 NAS，可作为大容量暂存候选；容量是时点值，使用前重新核验挂载、可用空间和权限。测试应隔离工作目录，限制配额，发现挂载异常立即停止，防止写满系统盘。

境内网络通过软路由 OpenClash 分流，已有代理有流量额度。若启用 VPS 代理备用路径，先确认软路由现有规则及优先级，为指定 VPS 出口制定可验证的路由，并核对百度网盘与 NAS 分别走预期路径。先小流量核验实际出口和原有代理计量，再运行大任务。VPS 尚未确定，不预先修改现有规则或公开本地网络地址、配置与凭据。
