## 当前可用命令

在开发仓库工作目录、已有权限0700的私有任务父目录执行：

```sh
python3 -m fast_transfer.intake examples/ncbi-ecoli-protein/manifest.json
python3 -m fast_transfer.task --tasks-dir /PRIVATE/TASKS create examples/ncbi-ecoli-protein/manifest.json
python3 -m fast_transfer.task --tasks-dir /PRIVATE/TASKS show JOB_ID
python3 -m fast_transfer.task --tasks-dir /PRIVATE/TASKS download-next JOB_ID
```

前两步只核对输入/建本地任务；download-next才下载来源文件，没有百度上传或分享。一次只下载一个文件。上传使用独立`python3 -m fast_transfer.task_upload`，完整范围和参数见[上传说明](mvp-task-upload.md)。全部文件实际核验后可执行下面的私有导出；国内人工观察/领取收据命令见[私有交付说明](private-delivery.md)，清理命令见下文，不应调用原样例一次性脚本冒充。

```sh
python3 -m fast_transfer.task_handoff --tasks-dir /PRIVATE/TASKS JOB_ID \
  --output /PRIVATE/HANDOFF/new-handoff.json
```

输出父目录须本人所有且0700，文件必须不存在，创建0600并fsync。导出阻止合成后端、未核验文件、未知操作以及源/目标/摘要不匹配；清单带任务设置摘要和账号摘要，并返回导出文件SHA256。导出不触发网络或建链，不转移凭据。v2清单含审核manifest及摘要，保留公开来源/版本/分发依据，国内校验会检查它与已核验对象一致；不包含登录或上传会话。清单只包含最小核对元数据，应经明确范围的私有渠道交接，不能提交公开仓库。失败留下的文件须人工检查，不能覆盖。

## 未知或中断结果怎样处理

- 完整源落盘、收据保存前中断：`recover-source JOB_ID --index 0`只重验已有文件，成功后不重新下载。
- 不完整源：`restart-incomplete-source JOB_ID --index 0`是显式重启；只清理任务已知部分载荷。已经有远端操作意图、完整长度但需核验的文件或未知文件时拒绝。
- 上传/合并未知：`show`的unknown_operations非零时保留任务/会话，不删数据库、不换job ID重跑。唯一未知为commit时已有[只读精确对象完整核查](unknown-commit-inspection.md)，其他未知阶段仍未接管；不能把“不重发”称为全部恢复已实现。
- 本人原生分享若超时：不重复share set，先由本人核查对应分享记录。客户端退出码不足以单独证明分享成功，需看到结果并确认领取。既有原样例已分享，勿重复操作。

国内原生客户端对**后续新对象**可用的命令模板如下，前提是已通过私有清单明确新路径并核对fsid/大小/摘要；不要直接复用上轮终端的旧sample_path：

```sh
BaiduPCS-Go meta "$new_cloud_path"
BaiduPCS-Go share set -period=1 "$new_cloud_path"
```

这两步由本人分别触发，只给新任务建一次分享；省略-p由原生客户端随机生成提取码，链接和提取码只进入私有交付。它们不是本轮已执行命令。

## 核验后逐文件释放磁盘

一个文件进入真实`cloud_verified`后即可清理，不必等待同任务全部文件上传或分享。这允许串行任务复用磁盘；全部文件核验后仍可导出交接清单。命令只操作显式指定任务文件，不访问网络或删除云端数据：

```sh
python3 -m fast_transfer.task_cleanup --tasks-dir /PRIVATE/TASKS JOB_ID --index 0
```

真实后端绑定、已保存完整回读收据、源收据与精确目标必须匹配，且任务不能有未知写入。清理重新读取对应本地载荷并核对大小/MD5/SHA256，持久保存删除意图后，核对文件身份再unlink并同步目录，最后更新`cleaned`。保留SQLite、全部源/上传/核验收据和其他文件；不递归删除任务目录，不改变`delivered=false`。

意图已落盘但文件尚在时，重运行只在同一文件身份和摘要匹配时继续；文件已删但完成状态未写时，重运行根据意图补记完成。没有删除意图却缺失文件、已清理后文件重现、内容/身份变化、软硬链接、合成任务和未核验任务均保留待人工核查，不能删除状态后强行继续。不要在任务目录内并发手工替换文件；任务锁用于同一操作员的协作进程，不是针对同UID恶意进程的隔离边界。
