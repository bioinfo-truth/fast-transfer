## 已完成的工程修复（同目录续办已使用）

- 默认 PinnedBaiduHTTPClient 仍独立禁止写入，普通 M3/工作流入口仍仅模拟；新增一次样例入口只接受固定文件名/长度/双摘要、账号指纹、批准引用、新随机目标和短期内存 RuntimeGrant。
- SampleHTTP 固定 rtype=0 目录、rtype=1 文件、is_revision=0；每个客户端的目录/预上传/分片/提交意图至多一次；仅本轮明确核实的本地错误允许一次同目录新会话续办。写入参数与载荷 SHA-256 不符先于凭据/DNS拒绝。显式 launcher 的独占批准标记阻止同一次工作区重复启动，不是对未来测试的持续许可。
- 复用现有源闸门、SpaceGuard、完整回读、原子状态和停止保护；真实样例资格与模拟资格分离，本样例云端通过也不自动标 delivery_eligible 或 delivered。
- [上传域名官方文档][host]明确使用 error_code=0；绑定已修复为只对 locateupload 接受该信封，非零/布尔/未知错误仍失败，没有放宽其他控制响应或 TLS/主机检查。
- 新增预上传后、节点查询前的私有会话检查点，记录 uploadid/目录身份/源哈希/账号指纹，0600 独占文件；不含访问/刷新令牌。普通任务 JSON 不记录原始会话标识，独立私有文件不得推送公开库。本次续办保留了新会话检查点；没有复用已丢失的旧标识，也没有实现通用跨进程续传。
- 新增有界、脱敏响应信封诊断，只记录标准错误码存在性/整数值，不留原始 URL/响应/令牌。首次失败与修复后的实测分别记录，原始失败没有被覆盖。
